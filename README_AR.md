# MY JOURNEY — Android (نسخة تجريبية)

المشروع يستخدم WebView محليًا ويحفظ بيانات الأهداف على الجهاز. يتضمن:
- تذكيرًا يوميًا بأهداف الغد (إشعار محلي).
- خيارًا في الإعدادات لإظهار إشعار بأهداف اليوم عند فتح قفل الهاتف.
- Widget للشاشة الرئيسية يعرض تقدم أهداف اليوم.

## بناء APK من الموبايل عبر GitHub Actions
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **محتويات** هذا المجلد إلى المستودع، بحيث يظهر مجلد `.github/workflows` في الجذر.
3. افتح تبويب Actions في المستودع وفعّل Actions إذا طُلب منك.
4. اختر `Build MY JOURNEY APK` ثم `Run workflow`.
5. بعد انتهاء البناء بنجاح، افتح التشغيل الأخير ونزّل Artifact باسم `MY-JOURNEY-debug-apk`.
6. فك ضغط Artifact وثبّت `app-debug.apk` على هاتفك.

## إعدادات الهاتف
- وافق على إذن الإشعارات عند أول تشغيل.
- من إعدادات MY JOURNEY فعّل «إظهار أهدافي كلما فتحت الهاتف».
- لإضافة Widget: اضغط مطولًا على الشاشة الرئيسية > Widgets > MY JOURNEY.
- في سامسونج، قد تحتاج السماح للتطبيق بالعمل في الخلفية من إعدادات البطارية.

## توضيح مهم
أندرويد لا يضمن فتح نافذة تطبيق فوق كل شاشة عند كل فتح للهاتف؛ الميزة هنا ترسل إشعارًا بعد فتح القفل، وقد لا يظهر كنافذة منبثقة حسب إعدادات الإشعارات ووضع عدم الإزعاج. إشعار فتح القفل لا يظهر إلا عند تفعيل الخيار والسماح بالإشعارات.

## معلومات البناء
- Package ID: `com.myjourney.app`
- Version: `1.1` (debug APK)
- minSdk: 23; targetSdk: 35; Java: 17
- بيانات الأهداف محلية داخل WebView، ولا تُرسل إلى خادم.
